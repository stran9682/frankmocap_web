# Frankmocap Web
A web interface for Frankmocap to convert videos to animated GLB/GLTF 3D models.

## Setup

### Requirements:
- Windows
- CUDA 13.2 
- NodeJS

### Steps
1. Inside `/backend` Run `install.py`
and `pip install fastapi`
2. then for the UI, `npm install` and `npm run dev` to launch the UI
